# glossary/

중국어-한국어 단어집 자료. `scripts/build-glossary.mjs` 가 읽어 `src/data/glossary.json` 을 만든다.

## 원리

한국 서버(`kr`)와 중국 서버(`cn`)의 스토리 스크립트는 줄 구조가 같아서 줄 단위로 1:1 대응한다.
이 병렬 말뭉치에서 다음을 자동으로 뽑는다.

- **회화 표현 후보**: 자주 나오는 중국어 대사와 같은 자리의 한국어 번역. 앞뒤 말줄임표를 떼어 같은 표현으로 묶는다. 인명·지문·말더듬은 제외한다.
- **빈도와 출처**: 직접 정리한 표현·단어가 스토리 몇 편에 나오는지, 예문은 어느 스토리인지.

오퍼레이터·아이템 같은 고유명사는 단어집에 넣지 않는다. 오퍼레이터의 중국어 이름은 `/operator` 목록과 상세 페이지에서 바로 보여 준다.

## 파일

| 파일 | 내용 |
| --- | --- |
| `phrases.json` | 직접 정리한 회화 표현. 병음, 번역, 직역, 단어별 해설 |
| `words.json` | 직접 정리한 단어 뜻풀이 |
| `phrase-candidates.json` | 아직 정리하지 않은 표현 후보 (빌드마다 갱신, 직접 편집하지 말 것) |
| `candidates.json` | 아직 정리하지 않은 단어 후보 (빌드마다 갱신, 직접 편집하지 말 것) |

## 회화 표현 추가하기

`phrase-candidates.json` 에서 쓸 만한 문장을 골라 `phrases.json` 에 추가한다.

```json
{
  "cn": "我明白了。",
  "pinyin": "wǒ míngbai le",
  "kr": "알겠습니다",
  "literal": "나는 이해했다",
  "words": [
    { "cn": "我", "pinyin": "wǒ", "kr": "나" },
    { "cn": "明白", "pinyin": "míngbai", "kr": "이해하다, 알다" },
    { "cn": "了", "pinyin": "le", "kr": "완료·변화를 나타내는 조사" }
  ],
  "note": "상대의 설명을 알아들었을 때"
}
```

`words` 는 글자가 아니라 단어 단위로 나눈다(明白은 한 단어). 조사는 뜻 대신 기능을 적는다.
`npm run glossary` 를 돌리면 빈도와 출처 스토리가 자동으로 붙는다.

발음 듣기 버튼은 브라우저 내장 음성 합성이 읽어 주므로 따로 준비할 것이 없다. 다만 기기에 중국어 음성이 없으면
버튼이 표시되지 않는다 (윈도우는 언어 설정에서 중국어 음성 추가, 안드로이드는 Google 음성 데이터 설치가 필요).

## 단어 추가하기

`candidates.json` 은 스토리에서 자주 나왔지만 아직 뜻풀이가 없는 중국어 n-gram 목록이다. 통계로 뽑은 것이라
`的人`, `是我` 처럼 단어 경계를 걸친 조각이 섞여 있으니, 실제 단어만 골라 `words.json` 에 추가한다.

```json
{ "cn": "知道", "pinyin": "zhīdào", "kr": "알다, 알고 있다", "category": "동사", "note": "생략 가능" }
```

`category` 는 세계관 / 명사 / 동사 / 형용사 / 부사 / 대명사 / 접속사 / 조사·어기 / 수량 / 인사·감탄 중 하나.
추가한 뒤 `npm run glossary` 를 돌리면 빈도와 예문이 자동으로 붙는다. 한 번에 다 하지 않고 조금씩 늘려도 된다.

세계관 고유명사는 한국 서버 공식 표기를 따른다. 확인이 필요하면 `gamedata/kr/gamedata/excel/` 의 테이블을 직접 찾아본다.
